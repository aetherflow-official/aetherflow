SECURITY PROTOCOL // ZERO TELEMETRY

PRIVACY POLICY

AetherFlow was built on a foundational principle: Your desktop belongs to you. We do not track you, we do not log your habits, and we do not sell data. Here is our absolute commitment to your privacy.

⚡ APPLIES TO: AETHERFLOW v1.0.0+ ⚡ LAST REVISED: SEPTEMBER 2026 ⚡ JURISDICTION: GLOBAL STANDARDS
CORE COMMITMENT

1. LOCAL-FIRST COMPUTING ARCHITECTURE

AetherFlow operates entirely offline by default. All core wallpaper rendering engines—including local 4K MP4 playback, Canvas 2D procedural simulations, high-resolution static artwork, and theme customizations—execute strictly on your local hardware.

No Mandatory Cloud Account: You can download, install, and run AetherFlow indefinitely without providing an email, username, or signing into any cloud service.
  • Local Storage: Your wallpaper configurations, monitor assignments, custom theme values, and volume adjustments are saved exclusively to your local device (in %APPDATA%\AetherFlow or sandboxed package storage).
  • No Telemetry Pings: The app does not include Google Analytics, Mixpanel, Sentry beacons, or background telemetry trackers.
HARDWARE INTEGRITY

2. AUDIO VISUALIZATION & PERIPHERALS SAFETY

AetherFlow includes an audio-reactive spectrum engine that animates procedural wallpapers in response to system sound.

  • Real-Time In-Memory FFT: When enabled, audio frequency spectrums are calculated strictly in transient RAM using standard Web Audio API fast Fourier transforms.
  • Zero Recording or Transmission: Audio signals are never recorded, compressed, stored to disk, or transmitted outside your local machine.
  • Microphone Safety: AetherFlow does not listen to room conversations. Microphone scanning is strictly on-demand when explicitly testing audio inputs.
Camera Hardware Suppression: AetherFlow permanently disables Chromium video-capture modules (--disable-video-capture and MediaFoundationVideoCapture suppression) at the engine level. AetherFlow cannot and will never access your webcam.
OPTIONAL SERVICES

3. OPTIONAL CLOUD FEATURES & THIRD PARTIES

Certain features interact with third-party networks only when explicitly initiated by the user:

  • Community Hub (Supabase): If you choose to publish a custom wallpaper or browse online community packages, requests are made securely to our Supabase database over HTTPS / TLS 1.3. Creating an author account requires an email address managed securely by Supabase Auth.
  • Web Streams & YouTube: If you configure a live web stream or YouTube URL as your desktop background, network packets travel directly between your device and the media hosting provider. Those streams are governed by the hosting provider's privacy policy.
  • GitHub Releases Updater: When checking for software updates, AetherFlow queries the public GitHub Releases API (api.github.com/repos/aetherflow-official/aetherflow/releases). No identifying user tokens are passed.
USER CONTROL

4. DATA RETENTION & COMPLETE DELETION

Because AetherFlow stores its settings locally, you have total authority over your data at all times:

  • Reset Preferences: You can reset all application data to default values directly inside Settings → Reset to Defaults.
  • Complete Uninstallation: Uninstalling AetherFlow removes the binary and its packaged assets. To remove all cached preferences, simply delete %APPDATA%\AetherFlow.
  • Community Account Deletion: If you have created a community publisher account and wish to delete your uploaded submissions or author profile, you can request immediate removal via our GitHub support channel.
CONTACT & TRANSPARENCY

5. OPEN SOURCE TRANSPARENCY & INQUIRIES

We believe security through obscurity is no security at all. AetherFlow's source code, release tags, and issue tracker are publicly verifiable on GitHub.
