AETHERFLOW PILOT MANUAL

Welcome to the operational manual for AetherFlow. Everything you need to know about pinning live wallpapers to the Windows desktop, configuring multi-monitor matrices, applying anime visualizers, and maximizing performance.

CHAPTER 01

1. INSTALLATION & INITIAL LAUNCH

AetherFlow is distributed in two official Windows formats:

Option A: Standalone Executable (Portable)

The fastest way to experience AetherFlow. No installer wizard required.

  1. Download AetherFlow.exe (~8.2 MB) from the Downloads section.
  2. Place the executable in any folder of your choice (e.g. C:\Tools\AetherFlow\ or your Desktop).
  3. Double-click to launch. AetherFlow initializes its desktop layer immediately.

Option B: Signed MSIX Package

Provides seamless Windows 11 integration, clean App list registration, sandboxed security, and Windows Startup toggle support.

  1. Download AetherFlow_1.0.0_x64.msix (~209 MB).
  2. Ensure the developer certificate is trusted on your machine (see Chapter 02 below).
  3. Double-click the .msix file and click Install.
CHAPTER 02

2. MSIX CERTIFICATE TRUST SETUP

Because AetherFlow is released directly as independent freeware, Windows requires our Package Identity certificate to be added to your local machine's trusted certificate store before installing the MSIX package.

Quick 1-Click Method: If you downloaded the repository or packages bundle, simply right-click install_cert.bat and select Run as Administrator.

Manual Certificate Installation (30 Seconds):

  1. Right-click AetherFlow_1.0.0_x64.msix → Click Properties.
  2. Select the Digital Signatures tab → Select the signer (AetherFlow Developer) → Click Details.
  3. Click View Certificate → Click Install Certificate...
  4. Select Local Machine (requires Administrator prompt) → Click Next.
  5. Select Place all certificates in the following store → Click Browse...
  6. Choose Trusted Root Certification Authorities (or Trusted People) → Click OK → Click Finish.

Once imported, double-clicking the MSIX file will open the Windows App Installer with a verified signature and a blue Install button.

CHAPTER 03

3. WALLPAPER ENGINES & MEDIA IMPORT

AetherFlow features four specialized rendering pipelines built to handle diverse media types:

1. High-Performance Local Video Engine

Plays 1080p, 4K, and ultra-wide video clips with hardware-accelerated decoding.

  • Supported formats: .mp4, .webm, .mkv, .mov.
  • How to add: Click + Add Media in the top header or navigate to Library → Import Video.
  • Seamless looping: Videos loop continuously with zero stutter or frame drops.

2. Live Web Streams & YouTube

Transforms live YouTube streams, animated HTML5 canvases, and web video feeds into desktop backgrounds.

  • Click Add Web Stream on the Home dashboard.
  • Paste your YouTube stream URL or live stream link (e.g. Lofi Girl, 24/7 Tokyo live cams, or custom web shaders).
  • AetherFlow strips player chrome and pins the stream frameless behind desktop icons.

3. Procedural Canvas 2D Simulations

Lightweight, math-driven visual engines written strictly in Canvas 2D:

  • Matrix Rain: Classic digital glyphs with phosphorescent green glow.
  • Cyber Particles: Constellation particle mesh reacting to cursor proximity.
  • Synthwave Grid: 80s neon wireframe highway with undulating horizon mountains.
  • Deep Space: Starfield warp drive simulation with customizable warp speed.
  • Aurora: Soft atmospheric light waves designed for calm focus.
  • Tokyo Rain: Neon drizzle on window glass with city reflections.
  • Quantum Flux: Vibrant kinetic plasma field.
CHAPTER 04

4. REAL-TIME PLAYBACK CONTROLS

The Active Controls Bar on the Home dashboard provides instant desktop adjustments without restarting the engine:

  • Opacity Slider (0% - 100%): Blend the wallpaper into a solid backdrop. Allows high-contrast icons to pop or creates a moody ambient aesthetic.
  • Brightness Slider (20% - 150%): Darken intense video scenes or elevate shadow details.
  • Playback Speed (0.25x - 3.0x): Slow down energetic video loops for relaxing ambient motion or accelerate procedural flow.
  • Volume Control & Mute: Independently control audio output for video wallpapers with soundtracks without affecting your Windows master volume.
CHAPTER 05

5. AUDIO SPECTRUM REACTIVE ENGINE

Transform your desktop into a responsive audio visualizer synced to music, gaming audio, and voice calls.

  • Navigate to the Audio tab in the sidebar.
  • Toggle Enable Audio Reactivity to ON.
  • Select your preferred loopback audio device (e.g. Default Audio Output or Stereo Mix).
  • Tuning Sliders: Adjust Sensitivity (amplification of quiet tracks), Frequency Smoothing (fluidity of bar bounce), and Decay Rate.
Zero Audio Telemetry: Audio calculation occurs strictly in volatile memory using the Web Audio API FFT analyzer. No recordings or transcripts are ever created.
CHAPTER 06

6. MULTI-MONITOR MATRIX CONFIGURATION

AetherFlow is engineered for modern multi-display battle stations:

  • Automatic Display Topology: Detects primary and secondary monitors, refresh rates (60Hz, 144Hz, 240Hz+), and display scale factors (100%, 125%, 150%, 200%).
  • Per-Display Mode: Assign a different live wallpaper to each connected monitor (e.g. Cyberpunk GT-R on Display 1, Matrix Rain on Display 2).
  • Spanning Matrix Mode: Span an ultra-wide 32:9 or 48:9 panorama video wallpaper across all monitors.
  • DWM Seamless Alignment: Compresses Windows non-client margins to ensure wallpapers align pixel-perfect with no border gaps.
CHAPTER 07

7. THEME STUDIO & TASKBAR PERSONALIZATION

Customize both the application's appearance and the Windows Taskbar:

Built-In Themes:

Select from 8 crafted presets: Sovereign, Dark I, Light I, Day I, Obsidian, Cyberpunk, Emerald, and Sakura.

Live Theme Studio:

Open the Theme Editor in Personalization to tune CSS custom properties live. Modify brand tints, neon glow radius, card opacity, and bevel highlights, then export your custom palette as a JSON profile.

Windows Taskbar Styling:

In Personalization → Taskbar Integration, choose how the Windows Taskbar interacts with your live wallpaper:

  • Transparent: Strips the taskbar background, letting the wallpaper flow behind system icons.
  • Acrylic Blur: Modern frosted glass aesthetic with adaptive luminosity.
  • Color Matched: Automatically tints the taskbar to match your active theme's accent color.
CHAPTER 08

8. HARDWARE ERGONOMICS & GAME MODE

AetherFlow is designed to be invisible to your hardware when performance matters:

  • Automatic Fullscreen Game Suppression: Detects when a 3D game, emulator, or CAD application enters fullscreen. The live wallpaper engine immediately suspends execution, dropping CPU and GPU consumption to 0.0%.
  • Battery Preservation: Automatically throttles animation frame rates to 30 FPS when running on laptop battery power.
  • OLED Deep Blackout Screensaver: Enables an intelligent idle timer that transitions the desktop into pure #000000 OLED blackout, preventing panel burn-in.

CHAPTER 10

10. TROUBLESHOOTING & FREQUENTLY ASKED QUESTIONS

Q: Why does Windows SmartScreen show "Unknown Publisher"?

A: Because AetherFlow is an independent community project signed with a self-generated developer certificate. To run the portable EXE, click "More info" → "Run anyway". For the MSIX, run install_cert.bat as Administrator once.

Q: Why is my video wallpaper paused?

A: Check if a game or browser window is currently running in exclusive fullscreen mode. AetherFlow's Game Suppression automatically pauses to conserve GPU power. You can toggle this behavior in Settings → Game Pause Mode.

Q: Where are my downloaded and imported wallpapers stored?

A: All local media files and configuration profiles reside in:

%APPDATA%\AetherFlow\

Q: How do I report a bug or suggest a feature?

A: We actively track issues on our official GitHub repository: https://github.com/aetherflow-official/aetherflow/issues.
